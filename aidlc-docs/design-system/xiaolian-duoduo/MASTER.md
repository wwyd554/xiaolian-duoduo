# 销练多多 · 界面设计规范

日期：2026-10-30。首次落地范围：首页、场景卡片、筛选栏、导航与全局 MUI 基础主题。

## 产品与使用情境

面向销售人员、销售新人和团队培训负责人。用户描述销售难题，确认 AI 生成的场景后练习；也可以从场景库直接开始。练习结束后查看复盘。界面应专业、清晰、有亲和力，降低开口练习的压力。

## 字体与层级

字体栈：Noto Sans SC → PingFang SC → Microsoft YaHei → system-ui。优先使用电脑已有中文字体，页面不依赖额外的远程字体请求。

- 首页标题 27–38px，700 字重，1.35 行高。
- 区块标题 21–24px，700 字重。
- 场景标题 17px，600 字重，卡片中显示一行；完整标题可通过卡片进入练习确认页查看。
- 输入 / 主要正文 16px，1.7–1.8 行高。
- 描述 / 控件 14px；辅助资料 13px；简短标签 12px。
- 普通文字对比度至少 4.5:1。完整的按钮标签不裁切。

## 布局与组件

- 4/8px 间距体系；组件内部 16/24px，区块间 24/32px。
- 主内容最大宽度 1360px；场景输入区最大宽度 880px；手机两侧 16px。
- 控件圆角 12px、场景卡片 20px、场景输入容器 24px；发送和预设提示词保持胶囊形。
- 输入区包含可见标签、示例、手动创建和发送。预设提示词只填入输入框，由用户发送后进入生成确认流程。
- 场景卡片按用户新参考图采用约 1.8:1 宽高比，最小高度 176px、18px 内边距。标题、练习目标分别占一行；标签自然换行；底部客户姓名和职位分两行，36px 圆形卡通头像。半透明白底配白色细边，背景色可柔和透过。
- 卡片包含标题、练习目标、行业/难度/时长、客户资料。点击卡片进入练习确认。三点菜单独立提供修改、删除、收藏。
- 筛选栏保持独立的小控件；选中状态同时通过文字/勾选/背景提示。搜索可清空。
- 侧栏用浅蓝选中态对应品牌主操作，底部保留圆形资料入口。
- 交互目标优先达到 44×44 CSS px；焦点环 2px，外偏移 3px。

## 交互与实现

- 使用 React 19 + TypeScript + MUI 7，真实数据和原有业务流程继续使用现有服务。
- 颜色、圆角、阴影、字体集中在 `frontend/src/theme/designTokens.ts`。
- MUI 基础主题集中在 `frontend/src/theme/theme.ts`。
- 默认 / 悬停 / 焦点 / 禁用状态有明显区分；发送空内容时禁用。
- 交互过渡约 160ms。首页使用两层蓝紫色柔光背景，24/32 秒缓慢循环，仅动画 transform/opacity。减少动态效果时静止，页面不可见时暂停；背景不可聚焦，不接收点击。
- 页面语言与应用设置同步；按钮文案由 i18n 管理并防止浏览器二次翻译改写。

## 验收

375px、768px、1440px 下不出现页面横向溢出；200% 缩放和减少动态效果后主要操作可用。验证预设填入、发送状态、筛选、搜索、三点菜单及场景进入；删除流程只检查确认与取消，不删除真实场景。

## 场景卡片头像

默认使用圆形卡通人物头像代替姓氏文字；已有自定义图片优先。默认形象在场景卡片、练习确认页、对话和复盘中保持一致，不依据姓名推断客户的性别或年龄。资源加载失败时显示人物图标。卡片和消息使用本地 144px WebP；练习确认页使用 320px WebP，适配大头像及高像素密度屏幕。生成记录见 [avatar-generation.md](avatar-generation.md)。
