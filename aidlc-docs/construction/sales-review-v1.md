# 销练多多：销售复盘第一版

## 已实现

- /history 统一展示平台陪练、聊天导入、录音转写导入，支持来源筛选、分页及后台分析状态刷新。
- 侧栏合并为销售复盘；原 /audio-analysis 地址跳转至录音筛选。
- 导入文字或 UTF-8 TXT，先填写标题、背景与目标，再确认和修改双方角色、原文。
- 一次导入最多 200 条消息、30000 字，必须包含销售与客户双方。
- 导入成功即保存到 SQLite；复用已有 jobs 队列与 Worker 生成报告，支持失败重试。
- 报告包含沟通总结、阶段判断、原文编号引用、下一句建议和判断局限。
- 导入记录通过 UUID 实现相同请求幂等，所有查询按当前用户隔离。

## 本版边界

- 录音仅支持已转写文字；没有新增原始音频上传或自动转写。
- 不支持截图 OCR，也不自动读取微信。
- 消息需手动标明“我：”“客户：”，每条一行；不推断时间戳或沉默时长。
- 脱敏由用户导入前处理，未实现自动脱敏。
- 尚未实现真实沟通一键转陪练、产品资料库和客户长期跟进。
- 本版新增页面文案为中文。

## 接口与数据

- GET /reviews?source=all|practice|chat|audio&page=1：统一列表。
- POST /reviews/import：保存经过用户确认的消息，并原子入队。
- GET /reviews/{id}：导入详情、原文、分析状态与报告。
- POST /sessions/{id}/analysis-retry：复用现有报告重试入口。
- 新增 review_imports 表，保存来源及背景；sessions/messages/analysis_reports/jobs 继续复用。
- 既有数据库通过 CREATE TABLE IF NOT EXISTS 增量创建表，不修改原始练习记录。
