# 单条复盘删除

日期：2026-11-05。

## 页面行为

- 销售复盘列表每条记录右侧增加三点操作菜单，选择“删除复盘”。
- 确认弹窗显示记录名称，说明原始对话和报告将永久删除。进行中的练习、生成中的报告会显示相应提示。
- 取消不发送删除请求；提交期间防止重复点击。失败留在弹窗内提示并支持重试。
- 成功后更新列表与总数；删除当前分页最后一条时返回前一页，保持来源和状态筛选。
- 陪练、导入聊天、导入录音使用同一个删除流程。

## 接口与数据

`DELETE /reviews/{session_id}` 需要登录，只允许操作本人记录；不存在、已删除或非本人记录返回 404。

在单个 SQLite 写事务内删除该会话的消息、分析报告、导入背景、会话状态、工具审计和复盘任务，再删除会话。场景与其他复盘不随之删除；任何步骤失败都会回滚。

删除任务租约后，旧 Worker 无法保存结果。入队前检查会话存在，状态保存使用受会话归属约束的原子写入；对话模型完成后也会检查会话仍然存在，避免迟到的输出重新写回。
